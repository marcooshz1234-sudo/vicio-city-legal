Politica de privacidad de "Vicio City Fabrica"

Ultima actualizacion: 27 de noviembre de 2026.

"Vicio City Fabrica" es una herramienta privada que usa el titular de las cuentas de "Vicio City" (YouTube, TikTok @vicioocity e Instagram) para publicar en sus propias cuentas los clips de video que el mismo prepara y aprueba. No es un servicio para el publico ni para otros usuarios.

Que datos usamos

  • Datos basicos de las cuentas del propio titular (identificador, nombre de usuario o canal) que cada plataforma entrega al iniciar sesion.
  • Los tokens de acceso que Google/YouTube, TikTok e Instagram conceden, necesarios para subir y publicar los videos que el titular aprueba.
  • Los videos, titulos y descripciones que el titular decide publicar.

Para que

Solo para subir y publicar en las cuentas del titular los videos que el ha aprobado manualmente. No se venden, ceden ni comparten datos con terceros, no se usan para publicidad y no se accede a datos de otros usuarios.

Servicios de API de YouTube y Google

La herramienta usa los Servicios de API de YouTube. Al usarla se aplican los Terminos de Servicio de YouTube y la Politica de Privacidad de Google. El uso de la informacion recibida de las API de Google se ajusta a la Politica de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado. El titular puede revocar el acceso en security.google.com/settings/security/permissions.

Donde se guardan

Los tokens y datos se guardan unicamente en el ordenador del titular, en un archivo protegido, y nunca se envian a otros servidores salvo a las propias API de YouTube, TikTok e Instagram para publicar.

Cuanto tiempo

Mientras el titular mantenga conectada la herramienta. Puede revocar el acceso en cualquier momento desde cada plataforma (en TikTok: Ajustes, Seguridad, Apps y servicios) y borrar los datos locales.

Contacto

Para cualquier consulta sobre privacidad: el titular de la cuenta @vicioocity, a traves de los mensajes directos de la cuenta.
